# Using Pabloooo

Choose your budget-cycle start day on first launch. A start day of 25 means each cycle runs from the 25th through the day before the next cycle. February and other short months clamp later start days to their final day.

On Home, tap **Add expense** or **Add income**. Enter the amount, select a category, and optionally add a merchant or note. The date and time default to now and can be changed for earlier entries. Repeated merchant/note patterns and recent category usage inform on-device suggestions. Activity lets you search, filter, open and edit records.

Open **More → Categories** to create your own labels, choose colours or place a category under another category. Archived categories remain attached to historical records. You can restore archived categories from the category list. Parent/child expense totals roll up without counting a transaction twice.

In **Plan**, enter expected income for the current cycle. Add category budgets and savings goals. The available-per-day figure uses your plan, recorded expenses and upcoming scheduled costs. It is a planning aid, not a bank balance. Goals record money you have manually set aside; they do not create transactions. Use the spending-cut calculator to explore a smaller future cost.

In **More → Recurring entries**, create schedules for bills, subscriptions or income. Confirm a due occurrence when it actually happens; the app then records the transaction and advances the next due date. Pausing a schedule stops it appearing as an upcoming active cost. It does not delete historical payments.

In **Insights**, choose a period or custom inclusive dates. Tap chart intervals or use the Previous/Next controls for exact values. Category percentages use actual recorded income from the selected interval. Export that interval directly, or export all records from Settings & data.

Enable the two daily reminders in **More → Settings & data**, accepting Android's notification permission. Check-in times use the phone's local clock. Android notification channels, force-stop and power restrictions affect delivery. Opening the app reconciles the schedules with your settings.

Use **Create a backup** before changing phones or clearing app storage. A JSON backup contains the complete journal, including deleted transaction markers. Restore validates the file and asks before replacing records. After restoring, explicitly enable reminders again. Spreadsheet exports are for analysis and do not restore into the app.

Choose a PNG shortcut icon in Settings to request a new home-screen shortcut. Android shows a confirmation dialog. The original app icon remains available; remove old shortcuts yourself if you no longer want them.
